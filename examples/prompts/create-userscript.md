# Create a reusable userscript

Inspect the current page and implement the additional user instructions as a standalone Violentmonkey userscript. Use a descriptive name, valid userscript metadata, a narrow @match for the intended site, and minimal permissions. Make repeat execution safe. Save to userscripts/<descriptive-name>.user.js and call offer_install. Do not install automatically or modify Boba. If the requested behavior is missing, ask the user what the script should do.
